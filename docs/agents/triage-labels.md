# 问题分类标签（Triage Labels）

工程技能会使用五个固定的 triage 角色。本文件把这些角色映射到本仓库 issue tracker 中实际使用的 label。

| mattpocock/skills 中的 label | 本仓库实际 label | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 需要维护者先评估。 |
| `needs-info` | `needs-info` | 等待提交者补充信息。 |
| `ready-for-agent` | `ready-for-agent` | 信息已经足够，可以交给 Agent 处理。 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或人工决策。 |
| `wontfix` | `wontfix` | 明确不处理。 |

当技能提到某个角色时，使用本表右侧对应的 label 字符串。
