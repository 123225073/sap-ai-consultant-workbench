# Phase 41 用户反馈优化审查记录

日期：2026-07-11

## 产品结论

- 核心 AI 能力来自用户配置的模型渠道，Codex CLI 只是可选的只读工程增强。
- SAP、模型、Feishu、Codex 四类能力相互独立；缺少其中一类不会错误阻塞其他功能。
- 配置中心按小页签单项展示，同类多连接纵向排列，避免大表单左右竞争视觉空间。
- SAP 验证状态放在左侧 Project 上下文中，Work 输入区不重复展示配置告警。

## 已实现

- OpenAI Compatible、Anthropic Compatible、DeepSeek 和自定义 OpenAI 协议。
- 同一 Project 最多 6 套纵向 SAP 只读连接，当前连接与密码引用分别保存。
- 远程、手工、远程失败回退手工三种模型目录策略，以及用户指定测试模型。
- 本机 Codex CLI 自动扫描；缺少时仅在用户确认后安装；拒绝安装不影响核心功能。
- 外部连接和运行错误改为中文用户提示，保留必要技术名词和安全脱敏。
- Electron 单实例锁、生命周期日志、一次受控恢复和异常退出诊断。
- 真实 Electron 静态构建启动、第二实例退出/聚焦与正常关闭日志检查。
- SAP 自动地址只使用 HTTPS；模型调用校验 DNS 解析地址并拒绝重定向。
- 模型请求在 DNS 校验后固定使用同一公网 IP，并保留原域名进行 TLS 校验；使用 `ipaddr.js` 拒绝本机、内网、云元数据、保留地址及 IPv6 过渡/非公网地址。
- SAP 与模型验证绑定启动时的连接配置；验证期间修改地址、账号、模型或密钥后，旧结果不会覆盖新配置。
- 同一配置并发发起验证时使用递增序号，只允许最后发起的请求保存结果。
- SAP 和模型渠道 ID 在进入安全存储前统一限长、去重，并验证最终密钥目标不会碰撞。
- 多 SAP 支持添加、切换和确认移除；取消移除保持原状，确认移除后持久保存并清理该连接的加密密码。
- 配置中心的首次本机能力扫描为静默扫描，不把无关提示带回 Work；手工扫描仍会明确反馈结果。
- Work 回复只概述成果数量，具体成果由回复下方文件按钮和右侧文件面板承载，不重复罗列内部维护文件。
- 规范中心真实版本与任务引用；知识库候选、审核、发布、过期、搜索和 Case 关联闭环。

## 对抗式审查修复

- 修复长前缀连接 ID 经过安全存储截断后可能碰撞的问题。
- 修复显式 HTTP SAP 地址仍可能发送 Basic 认证的问题。
- 修复切换连接或编辑同一连接时，迟到验证结果可能写错配置的问题。
- 修复新连接插入首位时可能继承旧连接凭据状态的问题。
- 修复模型域名二次解析可能造成 DNS 重绑定，以及部分 IPv6 非公网范围遗漏的问题。
- 修复相同配置的并发验证按完成顺序互相覆盖的问题。
- 修复移除 SAP 连接后加密密码残留，以及相关持久化探针可能假通过的问题。
- 将 renderer 恢复收敛为唯一受控 reload 调用点，避免重复恢复路径逐渐失控。

## 保留边界

- SAP 始终默认只读；未明确授权时不新增写入、激活、传输或过账。
- 真实外部连接仍需用户自己的网络、账号、权限和凭据。
- Daily Chat 当前借用所选 Project 的已验证模型渠道，尚未提供独立的全局个人模型配置。
- 本机能力扫描目前只识别 Codex CLI；后续增加其他工具时必须继续使用固定白名单与确认安装。
