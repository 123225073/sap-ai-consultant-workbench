# Phase 49 本地任务文件夹选择审查

审查日期：2026-07-13

## 结论

“新建任务 > 已有文件夹”现已改为打开 Windows 原生目录选择器，选择电脑上的真实本地文件夹，不再把当前页面已有的 Case 文件夹列表冒充为本地目录选择。

绑定本地文件夹只建立任务关联。系统不会在选择阶段遍历、复制、修改或删除原文件夹；任务对话与生成成果仍保存在工作台管理的 Case 目录中。后续若要让模型读取绑定目录，必须另行提供可见、受控、只读的文件导入或授权流程。

## 已确认

1. Renderer 只拿到一次性选择 token 和文件夹显示名，不拿到绝对路径。
2. 一次性 token 由 Electron main process 生成，十分钟过期，消费后失效。
3. 真实绝对路径只保存到本机专用绑定表，不进入 `app-state.json`、SQLite 搜索索引、模型上下文、日志或 Git。
4. 目录选择拒绝网络共享、符号链接、磁盘根目录、工作台目录及其父子路径和常见敏感系统目录。
5. 同一 Project 绑定同一真实目录时复用同一 Case；每个 Work 会话仍有独立会话 ID 和独立对话记录。
6. 切换 Project 会清空尚未使用的选择 token，避免把目录误绑定到另一个客户项目。
7. 页面使用“选择电脑文件夹”按钮和文件夹名称摘要，不再显示只包含“收件箱”的错误下拉框。

## 对抗性审查

- 伪造、过期或重复使用 token 会被拒绝。
- 选择原目录不会写入哨兵文件，也不会创建隐藏文件或工作台元数据。
- 工作台备份和旧数据导入不包含本机绝对路径绑定表，避免把本机目录结构泄露给另一台电脑。
- 原目录被移动、删除或失去权限时，已有 Case 记录仍可打开；系统不得伪造“原文件夹仍可访问”的状态。
- 本阶段不把任意本地目录直接暴露给模型，避免一次选择就扩大数据读取范围。
