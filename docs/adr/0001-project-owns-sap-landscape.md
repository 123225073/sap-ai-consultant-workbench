# ADR-0001：Project 管理 SAP landscape，而不是单一登录系统

## 状态

Accepted

## 背景

同一个客户或业务项目通常同时包含 DS4、QS4、PS4 等多个 SID，每个 SID 又可能包含多个 Client。案件分析、开发说明书和问题核对经常需要在这些系统之间交叉验证。把每个 SID 或 Client 建成独立 Project 会拆散规范、知识、案件和证据，也会迫使用户手工切换上下文。

## 决策

1. `Project` 表示客户或业务项目边界，可以拥有多套 `AdtConfig` 登录连接。
2. 每套连接独立保存 SID、实例号、环境、Client、用户、用途、路由关键词、验证状态和安全存储密码引用。
3. SAP GUI 本机配置只用于识别候选主机、SID 和实例号，不导入密码，也不自动绑定账号。
4. Work 只在真实 T000 验证通过的连接中路由。问题明确时选择单一连接；有歧义、跨系统意图或多个同分候选时先由用户确认。
5. 不匹配本机 SAP Logon 且未填写实例号时，禁止静默假设实例 `00`。
6. SAP 仍保持单对象、固定连接器路径和只读边界；跨系统仅表示对同一明确对象执行多个独立只读读取。

## 影响

- 用户可以在一个 Project 内维护完整 landscape，并让案件、规范和知识保持同一业务上下文。
- 配置中心需要按 SID 分组展示连接，左侧 Project 需要直达配置入口。
- 路由只是连接建议，不是授权；模糊读取需要额外确认。
- 密码和验证状态必须继续按 `Project + connectionId` 隔离。
