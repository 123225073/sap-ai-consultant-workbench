# 0.1.9 已知限制

1. 当前 Portable 和 Setup 未做 Authenticode 代码签名，可以安装和运行，但 Windows 可能显示“未知发布者”或 SmartScreen 提示；代码签名是提升分发信任的可选增强，不是个人使用的运行前置条件。
2. 应用已配置独立产品图标；它只表达 SAP 顾问工作与 AI 元素，不使用或仿冒 SAP 官方 Logo。
3. 本产品是个人独立工具，不是 SAP 官方产品；界面、安装包和说明不得暗示官方授权或认证。
4. 尚未实现自动更新和发布通道管理；升级依赖完整备份、受控导入和人工发布流程。
5. Feishu/Lark 当前只生成本地交接草稿，不在应用内创建或发布云端文档。
6. Codex CLI 只是迁移期可选兼容增强，失败不会阻塞 Work、Chat、规范、知识和本地文件；后续不再作为核心中转扩展。
7. 知识文件导入目前只支持 Markdown 和 TXT；其他格式需先转换并脱敏。
8. 只有完成最小对话测试的模型才能进入 Work 和 Chat。
9. SAP 只提供已验证 ADT 连接上的对象读取与有界业务数据读取，不提供任何写入、激活、传输、过账、删除或批量更新。
10. SAP 对象证据默认只向模型提供安全摘要；用户显式启用通用数据读取后，本轮模型会收到有上限的分析行以继续完成任务，完整明细保存在当前运维项目文件夹。使用外部模型渠道前，用户应确认公司的数据处理政策允许相应内容进入该模型。
11. Portable 只代表免安装；数据仍保存在当前 Windows 用户目录。
12. 跨 Windows 用户迁移后，受 `safeStorage` 保护的密钥必须重新输入。
13. 每次 schema 变化都必须新增显式迁移和故障注入测试。
14. 跨多个案件文件的写入采用原子单文件、版本历史和恢复快照，不等同于数据库事务。
15. 没有合格模型时生成的“待确认”结构不能直接作为正式交付物。
16. 知识发布会检查 SAP 对象与适用期重叠；语义冲突仍需顾问人工判断。
17. 系统崩溃前尚未保存的纯前端草稿仍可能丢失。
18. SAP 连接为适配企业内网自签证书而默认跳过证书校验；对可配置企业 CA 的环境，仍建议用户主动切换为严格校验。
19. Computer Use 在窗口被最小化或用户正在输入时会主动停止接管；项目使用 Electron CDP 的隔离桌面 UAT作为稳定、可重复的主要图形证据。
20. 独立 Agent Runtime 已具备事件账本、Work 只读工具循环、模型窗口感知预算、自动 checkpoint 和分层记忆基线；当前 checkpoint 为最多 240 条消息的本地确定性摘录，不是模型自动推理出的长期知识，完整原始会话仍保留，查看/重建界面尚未开放。
21. Skill 和声明式 Plugin 已可导入、校验、启停并按需进入新回合；Work 模型可搜索并加载已启用 Skill 指令，但导入包中的任意脚本、第三方 UI 代码和自动安装仍不执行。
22. MCP 稳定版只开放 HTTPS Streamable HTTP 的连接、测试和能力发现。任何外部 MCP 工具当前都不能启用、由页面直调或进入 Work 工具循环；STDIO、OAuth 自动登录、外部工具执行和 MCP Server 模式尚未开放。
23. Chat 使用提示词、记忆和长会话 checkpoint，但当前不自动调用 Work 的 Case/SAP/MCP 工具，避免普通对话意外触碰案件或外部系统。
24. 产品内受限子 Agent、OpenAI Responses API 专用适配器和跨进程长任务续跑仍属后续能力；当前版本不能宣称具备 Codex App 的全部编排能力。
25. 应用异常关闭后，只会自动续接具备完整恢复输入、没有模型增量、工具调用或产物进度、且业务投影尚未提交的 Turn；其余 Turn 会在原会话明确提示。外部系统已执行但本地事件尚未落盘的极端场景仍不能保证自动判定，因此写操作工具仍未开放。
26. 已从模型目录保留并使用合法的 `contextWindowTokens` 和 `maxOutputTokens`；渠道未提供这些元数据时仍回退到 32,768 token 保守窗口，不能据此推断模型厂商的真实极限。
27. SAP ADT 通用数据读取通过 `/sap/bc/adt/datapreview` 执行结构化、单数据源、有筛选且有行数上限的只读查询，可支撑库存、订单、凭证、主数据和配置等场景；它不会运行 SAP GUI 事务，也不能自动保证结果等同于 MB52 等标准报表口径。复杂跨源关联、历史口径和权限受限对象仍需拆分读取、补充 CDS/OData/API 或由用户提供报表文件。
28. Mermaid `.mmd` 已支持应用内静态预览和 SVG/PNG/PDF 导出；为避免执行配置、链接、HTML 或脚本，预览器只支持受限的 `flowchart` / `graph` 节点与连线语法，复杂 Mermaid 图表会保留源码并提示不支持。
29. MCP Header 只允许引用与当前 Project、MCP 连接和 Header 名称完全绑定的专用安全密钥；模型 API Key、SAP 密码和其他连接的密钥不能复用。全局 MCP 暂不允许引用 Project 密钥；MCP Header 密钥的页面录入仍待后续开放。
30. 当前 Case 可导入 PDF、DOCX、XLSX、CSV、TXT 和 Markdown：原件仅保存在当前 Case，本地生成的脱敏摘录才可被只读工具按需检索。受密码保护、损坏、超大或超出受限语法的文件会被拒绝；扫描版 PDF 不含 OCR，复杂 Office 排版也不会原样还原。
31. 编辑历史消息会保存可恢复的对话版本并撤销旧 checkpoint，但只回退当前线程的聊天上下文；运维项目共享文件、SAP 数据和外部系统状态不会自动回滚。
32. Work 现已对明确 SAP 只读意图执行确定性工具路由：未授权时明确提示开启对应工具，目标不明确时完成对象/数据源搜索，目标明确时可直接进入固定对象读取或字段发现，并在至少一次真实读取后才允许模型形成结论。该机制不会自动启用功能，也不会绕过 SAP 后端对象权限、Repository Search/Data Preview 服务状态或行数限制；模型渠道若忽略指定工具调用，任务会明确失败而不会退化成普通草稿。
