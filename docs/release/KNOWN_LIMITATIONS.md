# 0.1.0 已知限制

1. 当前验收包未签名，只能用于内部受控测试；正式门禁会拒绝未签名产物。
2. 尚未提供经品牌与法务批准的产品名、发布主体和正式 ICO，内部包仍使用 Electron 默认图标。
3. 当前名称不能证明 SAP 官方身份。没有书面授权时必须按独立兼容产品命名和发布。
4. 尚未实现自动更新和发布通道管理；升级依赖完整备份、受控导入和人工发布流程。
5. Feishu/Lark 当前只生成本地交接草稿，不在应用内创建或发布云端文档。
6. Codex CLI 是可选增强，失败不会阻塞 Work、Chat、规范、知识和本地文件。
7. 知识文件导入目前只支持 Markdown 和 TXT；其他格式需先转换并脱敏。
8. 只有完成最小对话测试的模型才能进入 Work 和 Chat。
9. SAP 只提供明确对象的只读能力，不提供任何写入、激活、传输、过账、删除或批量更新。
10. 完整 SAP 证据默认不发送给外部模型，模型只接收安全摘要。
11. Portable 只代表免安装；数据仍保存在当前 Windows 用户目录。
12. 跨 Windows 用户迁移后，受 `safeStorage` 保护的密钥必须重新输入。
13. 每次 schema 变化都必须新增显式迁移和故障注入测试。
14. 跨多个案件文件的写入采用原子单文件、版本历史和恢复快照，不等同于数据库事务。
15. 没有合格模型时生成的“待确认”结构不能直接作为正式交付物。
16. 知识发布会检查 SAP 对象与适用期重叠；语义冲突仍需顾问人工判断。
17. 系统崩溃前尚未保存的纯前端草稿仍可能丢失。
18. 已有演示 SAP 连接曾使用跳过证书校验模式；正式连接必须导入企业 CA 并切换为严格校验。
19. 本机 Windows build 19044 不支持 Computer Use 所需的截图接口；项目使用 Electron CDP 完成等价桌面 UAT。
