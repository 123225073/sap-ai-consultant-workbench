# 官方依据

- [SAP Signavio Modeling Notations](https://help.sap.com/docs/signavio-process-manager/user-guide/fa88cd406dad1014a4730ff5fb2ca89e.html)：支持的流程建模表示法。
- [Model a BPMN Diagram](https://help.sap.com/docs/signavio-process-manager/user-guide/model-bpmn?locale=en-US&version=SHIP)：BPMN 元素和建模流程。
- [Managing Modeling Conventions](https://help.sap.com/docs/signavio-process-manager/workspace-admin-guide/manage-modeling-conventions)：组织级 notation、label、layout 和必填属性规则。

Mermaid 是本产品的轻量渲染选择，不等于完整 BPMN 2.0 模型或 SAP 官方输出格式。
