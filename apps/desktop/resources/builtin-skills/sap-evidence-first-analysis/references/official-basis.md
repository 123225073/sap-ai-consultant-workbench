# 官方依据

- [Getting Support from SAP](https://help.sap.com/docs/built-in-support/user-guide-for-key-users/get-support-from-sap?locale=en-US)：摘要、症状、环境、组件、优先级、业务影响和附件。
- [Implementation Guidance for Case Creation](https://help.sap.com/docs/cloud-alm/apis/implementation-guidance-for-case-creation?locale=en-US&state=PRODUCTION&version=latest)：业务影响与优先级信息。
- [SAP KBA 3044927](https://userapps.support.sap.com/sap/support/knowledge/en/3044927)：业务场景、按时间顺序的复现步骤、期望/实际和正常对照。
- [Problem Management](https://help.sap.com/docs/SAP_Solution_Manager/0611cd2e5d1e403c9ee7b6efad89e81b/1f35fb5cda804e71bfcf5c00326eb1fa.html)：根因、防复发、Knowledge 和后续 Change。

事实/推断/假设/未确认四分法是本产品的质量控制设计，不是 SAP 强制栏目。
