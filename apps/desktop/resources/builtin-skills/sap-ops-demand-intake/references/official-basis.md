# 官方依据

- [SAP Activate Methodology](https://www.sap.com/products/erp/activate-methodology.html)：Fit-to-Standard 与生命周期语境。
- [SAP Cloud ALM Requirements](https://help.sap.com/docs/cloud-alm/applicationhelp/486b3301a36f49e38eacd9535ecbd9ff.html?locale=en-US)：业务需要、process context、owner、priority 和审批。
- [Requirement Traceability](https://help.sap.com/docs/cloud-alm/applicationhelp/requirement-traceability)：Requirement 与后续交付对象的追溯。

公司审批、估算和模板属于组织自定义；Skill 不假定客户使用 SAP Cloud ALM，但要求保留等价 ID 和关系。
