# SAP 运维发布与关闭模板

## 状态摘要

- 对象：Requirement / Change / Incident / Problem。
- 状态：GO / 条件 GO / NO-GO / 证据不足 / hypercare / 已关闭。
- Release/上线窗口、owner、approver、执行人和业务确认人。
- 当前风险、阻断项和下一门禁。

## 追溯与 Readiness

| 范围/验收项 | Spec/流程 | 对象/Transport | 测试/结果 | Defect | 状态 |
|---|---|---|---|---|---|

检查 ATC/Unit、功能/集成/验收、缺陷、授权、依赖/顺序、回退基线、通讯、监控和数据修复计划；所有未执行项显式列出。

## 发布、验证与回退

| 动作 | 是否获批 | 实际执行人/时间 | 结果/证据 | 回退触发 | 状态 |
|---|---|---|---|---|---|

生产验证至少覆盖业务结果、技术信号、重复副作用、关键回归和监控。未实际执行前不得预填成功。

## 关闭与 Knowledge

- hypercare 期间与信号。
- 业务 owner 接受/拒绝及证据。
- 遗留风险、owner、期限。
- Knowledge 候选：适用范围、识别信号、排查/处理、失效条件、来源。
- 规则来源：组织发布策略、系统路线、审批和 Case 例外的版本。
