# 官方依据

- [SAP Activate Methodology](https://www.sap.com/products/erp/activate-methodology.html)：Run 阶段与持续优化语境。
- [SAP Solution Manager ITSM](https://help.sap.com/docs/SAP_Solution_Manager/0611cd2e5d1e403c9ee7b6efad89e81b/ac038ce237754d979142e1abf80afa72.html)：Incident、Problem、Service Request 等对象模型。
- [Request for Change](https://help.sap.com/docs/SAP_Solution_Manager/8b923a2175be4939816f0981b73856c7/4c315d1fdcdd4ff695f350fc984b0647.html)：变更请求语义。

组织工单类型、SLA、升级路径和字段是可配置规则，不应冒充 SAP 统一要求。
