# SAP 运维汇报 / PPT 模板

## 先选模式

- 管理层：业务影响、趋势、风险、决策请求、owner 和日期。
- 业务评审：目标、As-Is/To-Be、范围、业务规则、验收和变化。
- 技术评审：证据、方案、对象、接口、测试、发布和回退。
- 事故复盘：时间线、影响、恢复、根因、改进、监控和责任。

## 默认页序

1. 标题、期间、状态和保密标识。
2. 一页结论：发生/需要什么、影响、当前状态、请求的决策。
3. 范围与事实来源。
4. 进展、趋势或 As-Is/To-Be。
5. 关键问题/方案及证据。
6. 测试、发布或恢复状态。
7. 风险、阻塞、owner 和截止时间。
8. 决策项与下一步。
9. 附录：技术细节、来源台账、口径和完整追溯。

按任务裁剪，不机械保留全部页面。

## 页面质量门禁

- 每页只有一个核心结论；标题直接表达结论。
- 数字注明系统、期间、口径、更新时间和来源。
- 风险有影响、概率/状态、缓解、owner、期限。
- 不虚构收益、完成率、根因或用户确认。
- 客户母版、品牌、术语和保密要求注明配置来源与版本。
